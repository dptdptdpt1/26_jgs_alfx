# 软考系统架构设计师案例分析

面向软考系统架构设计师“案例分析”科目的轻量考点库。

## 入口

- [高频重点考点](./高频重点考点/README.md)
- [写作规则](./AGENT.md)

## 使用方式

1. 先看 `高频重点考点/README.md`，建立案例分析的考点地图。
2. 先复习 01 常考图，再复习 P0 考点：质量属性、架构评估、架构风格、需求建模、数据库、MySQL、Redis、分布式与微服务、高可用、安全。
3. 按“概念 -> 场景 -> 取舍 -> 答题模板”复习。

## 维护原则

- 以考点为中心，不以题库为中心。
- 具体写作规则见 `AGENT.md`。
