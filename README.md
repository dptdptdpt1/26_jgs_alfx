# 软考系统架构设计师案例分析

这是一个面向“案例分析”科目的轻量考点库，当前只关注：

- 高频/重点考点：整理案例分析中反复出现、容易失分、适合模板化作答的内容。

## 目录

```text
.
├── README.md
└── 高频重点考点/
    └── README.md
```

## 使用方式

1. 先看 `高频重点考点/README.md`，建立案例分析的考点地图。
2. 复习时优先补充：常见问法、答题关键词、易错点、可复用表达。
3. 不维护历年真题原文，只保留对备考有复用价值的考点。

## 维护原则

- 以考点为中心，不以题库为中心。
- 每个考点尽量包含：常见问法、答题关键词、典型措施、易错点。
- 内容要短、稳、可复用，避免堆概念。
