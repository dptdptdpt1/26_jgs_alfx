# 软考系统架构设计师案例分析

这是一个面向“案例分析”科目的轻量考点库，当前只关注：

- 高频/重点考点：整理案例分析中反复出现、容易失分、适合模板化作答的内容。

## 目录

```text

```

## 使用方式

1. 先看 `高频重点考点/README.md`，建立案例分析的考点地图。
2. 优先复习 P0 考点：质量属性、数据库、MySQL、Redis、分布式与微服务。
3. 复习时补充：考试考法、技术原理、机制流程、适用场景、易混点。
4. 不维护历年真题原文，只保留对备考有复用价值的考点。

## 维护原则

- 以考点为中心，不以题库为中心。
- 每个考点只保留两个核心部分：考试中一般怎么考、针对考法梳理知识点。
- 技术类考点要写清楚原理和机制，避免只列措施名。
- 具体写作规则见 `AGENT.md`。
