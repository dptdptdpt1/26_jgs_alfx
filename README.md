# 软考系统架构设计师案例分析

这是一个面向“案例分析”科目的轻量文档项目，当前只关注两件事：

- 历年真题：沉淀题目索引、题型、知识点、答题思路和复盘。
- 高频/重点考点：整理案例分析中反复出现、容易失分、适合模板化作答的内容。

## 目录

```text
.
├── README.md
├── 历年真题/
│   ├── README.md
│   └── 题目模板.md
├── 高频重点考点/
│   └── README.md
└── 模板/
    └── 案例分析答题模板.md
```

## 使用方式

1. 遇到一套真题，先在 `历年真题/README.md` 登记年份、批次、主题和掌握状态。
2. 每道值得复盘的题，复制 `历年真题/题目模板.md` 新建独立文档。
3. 做完题后，把涉及的知识点回链到 `高频重点考点/README.md`。
4. 对反复出现的问法，沉淀到 `模板/案例分析答题模板.md`。

## 文件命名建议

真题文件建议使用：

```text
YYYY-上半年-案例-主题.md
YYYY-下半年-案例-主题.md
```

示例：

```text
2024-上半年-案例-质量属性.md
2023-下半年-案例-数据库与缓存.md
```
