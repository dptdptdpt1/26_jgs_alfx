# 高频/重点考点

本文件用于沉淀案例分析中反复出现的考点。每个考点都建议关联至少一道真题，逐步形成“考点 -> 真题 -> 答题模板”的闭环。

## 1. 质量属性

### 常见问法

- 系统应重点关注哪些质量属性？
- 某个设计方案提升了哪些质量属性？
- 为满足性能、可用性、安全性，应采取哪些架构措施？

### 答题关键词

- 性能：缓存、异步处理、批处理、索引优化、负载均衡、水平扩展。
- 可用性：集群部署、故障转移、冗余、健康检查、限流降级、容灾备份。
- 安全性：认证、授权、加密、签名、审计、防重放、最小权限。
- 可维护性：分层、模块化、低耦合、高内聚、接口隔离、配置化。
- 可扩展性：插件化、服务拆分、消息队列、接口标准化、无状态服务。

## 2. 架构风格与模式

### 常见问法

- 判断系统采用了哪种架构风格。
- 分析某种架构风格的优缺点。
- 针对业务场景选择合适架构。

### 答题关键词

- 分层架构：职责清晰、易维护，但跨层调用可能带来性能损耗。
- 微服务架构：独立部署、弹性扩展，但治理复杂、分布式一致性难度高。
- 事件驱动架构：解耦、削峰填谷、适合异步场景，但链路追踪和一致性更复杂。
- 管道过滤器：适合数据处理流水线，步骤清晰，可复用过滤器。
- MVC/MVP/MVVM：关注表示层职责分离，提高界面层可维护性和可测试性。

## 3. 架构评估

### 常见问法

- 识别风险点、敏感点和权衡点。
- 根据质量属性场景评价架构方案。
- 使用 ATAM 思路分析系统。

### 答题关键词

- 风险点：当前设计可能导致质量属性无法满足的设计决策。
- 敏感点：某个设计参数变化会显著影响质量属性。
- 权衡点：一个设计决策同时影响多个质量属性，且可能有正负两面。
- 质量属性场景：刺激源、刺激、环境、制品、响应、响应度量。

## 4. 数据库与缓存

### 常见问法

- 如何提高查询性能？
- 如何设计缓存？
- 如何保证数据一致性？
- 如何处理海量数据？

### 答题关键词

- 查询优化：索引、SQL 优化、读写分离、分页优化、冗余字段、物化视图。
- 缓存策略：旁路缓存、缓存预热、过期策略、热点数据缓存、防穿透、防击穿、防雪崩。
- 数据一致性：事务、补偿机制、消息最终一致性、幂等、重试、对账。
- 海量数据：分库分表、归档、冷热分离、分区表、搜索引擎。

## 5. 分布式与微服务

### 常见问法

- 服务如何拆分？
- 微服务架构有什么问题，如何治理？
- 分布式调用失败如何处理？

### 答题关键词

- 服务拆分：按业务能力、领域边界、数据归属、变更频率拆分。
- 服务治理：注册发现、配置中心、网关、限流、熔断、降级、链路追踪。
- 接口设计：版本管理、幂等设计、超时控制、重试策略、兼容性。
- 一致性：Saga、TCC、可靠消息、最终一致性、补偿事务。

## 6. 高可用与性能优化

### 常见问法

- 找出系统性能瓶颈。
- 设计高可用方案。
- 系统访问量增长后如何扩展？

### 答题关键词

- 性能分析：CPU、内存、磁盘 I/O、网络、数据库、锁竞争、外部接口。
- 扩展方式：无状态化、水平扩展、负载均衡、异步队列、缓存、分片。
- 高可用：主备、集群、健康检查、故障转移、多活、容灾、备份恢复。
- 稳定性：限流、熔断、降级、隔离、超时、重试、监控告警。

## 7. 安全架构

### 常见问法

- 系统存在哪些安全风险？
- 如何保证接口安全？
- 如何保护敏感数据？

### 答题关键词

- 身份认证：用户名密码、多因素认证、单点登录、Token。
- 访问控制：RBAC、ABAC、最小权限、接口鉴权。
- 数据保护：传输加密、存储加密、脱敏、密钥管理。
- 接口安全：签名、时间戳、Nonce、防重放、限流、输入校验。
- 审计追踪：操作日志、登录日志、异常告警、留痕。

## 8. 需求分析与建模

### 常见问法

- 识别功能需求和非功能需求。
- 补充用例、数据流、实体关系或状态转换。
- 分析需求变更对架构的影响。

### 答题关键词

- 功能需求：系统必须提供的业务能力。
- 非功能需求：性能、可靠性、安全性、可用性、可维护性、可扩展性。
- 建模工具：用例图、类图、顺序图、状态图、活动图、数据流图、ER 图。
- 需求变更：影响范围分析、接口兼容、回归测试、配置管理。

## 9. 项目与过程

### 常见问法

- 如何进行配置管理？
- 如何控制风险和质量？
- 如何组织测试和持续集成？

### 答题关键词

- 配置管理：版本控制、基线、变更控制、构建发布、配置审计。
- 风险管理：风险识别、分析、应对、监控。
- 测试：单元测试、集成测试、系统测试、性能测试、安全测试、回归测试。
- DevOps：持续集成、持续交付、自动化测试、自动化部署、监控反馈。
