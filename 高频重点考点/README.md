# 高频/重点考点

这是软考系统架构设计师案例分析的考点库。当前不维护历年真题原文，只沉淀可复用的考法、判断规则、关键词和易错点。

## 复习优先级

| 优先级 | 考点 | 原因 |
| --- | --- | --- |
| P0 | 质量属性 | 常考场景判定、质量属性场景、可靠性/可用性战术 |
| P0 | 数据库 | 高频工程题，容易问性能、海量数据和一致性 |
| P0 | MySQL | 常考索引、事务、读写分离、分库分表 |
| P0 | Redis | 常考缓存异常、缓存一致性和高可用 |
| P0 | 分布式与微服务 | 近年系统架构题常见背景 |
| P1 | 架构评估 | 常考 ATAM、质量属性场景、风险点和权衡点 |
| P1 | 高可用与性能优化 | 常见问题定位和改进题 |
| P1 | 安全架构 | 常和接口、数据、权限、审计结合 |
| P1 | 架构风格与模式 | 常考识别、选择、优缺点 |
| P1 | 系统集成与中间件 | 常考同步异步、消息队列、ESB、接口集成 |
| P1 | 常考图分类与详解 | 常考 UML、ER、DFD、流程图、盒图、PAD 图等辨析 |
| P2 | 云原生与容器化 | 近年常与微服务、DevOps、高可用结合 |
| P2 | 需求分析与建模 | 常考图、需求分类、变更影响 |
| P2 | 项目与过程 | 辅助性考点，常出现在综合问答中 |
| P2 | 嵌入式与物联网 | 不是每年必考，但出现时考法模板化 |

## 维护规则

- 每个考点文件只保留两个核心部分：考试中一般怎么考、针对考法梳理知识点。
- 技术类考点要写清楚原理、机制、流程、适用场景和限制。
- 表格只用于对比、枚举、速查，不作为强制格式。
- 不把题干全文放进知识库，只记录题目暴露出的考法、关键词和易错点。
