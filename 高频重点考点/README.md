# 高频重点考点

按新版系统架构设计师大纲和案例分析常见考法重排。每章只保留能直接服务案例分析的概念、场景、取舍和答题落点；偏考纲外但仍有识图或旧题价值的内容已在对应章节单独标注。

## 复习顺序

| 顺序 | 优先级 | 考点 | 复习目标 |
| --- | --- | --- | --- |
| 01 | P0 | 常考图分类与详解 | 先解决识图、补图、图间区别 |
| 02 | P0 | 质量属性 | 会判属性、写场景、选架构策略 |
| 03 | P0 | 架构评估 | 会写 ATAM、风险点、权衡点 |
| 04 | P0 | 架构风格与模式 | 会按场景选风格并说明代价 |
| 05 | P0 | 需求分析与建模 | 会区分需求、约束、模型和变更影响 |
| 06 | P0 | 数据库设计 | 会处理建模、一致性、拆分和分析需求 |
| 07 | P0 | MySQL | 会答索引、事务、主从、分库分表 |
| 08 | P0 | Redis | 会答缓存异常、一致性和高可用 |
| 09 | P0 | 分布式与微服务 | 会答服务治理、容错和分布式一致性 |
| 10 | P0 | 高可用与性能优化 | 会按瓶颈和单点给改进方案 |
| 11 | P0 | 安全架构 | 会答认证授权、接口安全、数据安全 |
| 12 | P1 | 系统集成与中间件 | 会选同步、异步、消息、ESB 和接口治理 |
| 13 | P1 | 信息系统总体架构 | 会从业务、应用、数据、技术、安全整体作答 |
| 14 | P1 | 系统计划与方案评估 | 会做可行性、方案比较和迁移计划 |
| 15 | P1 | 层次式架构设计 | 会划分职责、依赖和层间边界 |
| 16 | P1 | 云原生与容器化 | 会答容器、编排、弹性、发布和改造风险 |
| 17 | P1 | 大数据架构 | 会答采集、存储、处理、治理和数仓 |
| 18 | P1 | 通信与网络架构 | 会答网络分区、入口、协议和高可用 |
| 19 | P2 | 嵌入式与物联网 | 会答分层、实时性、网关、设备管理 |
| 20 | P2 | 架构演化与遗留系统改造 | 会答渐进迁移、兼容、数据迁移和回滚 |
| 21 | P2 | 构件化复用与标准合规 | 会答复用、接口标准、数据标准和合规 |
| 22 | P2 | 项目与过程 | 会答变更、配置、测试、质量和风险 |
| 23 | P2 | Java 技术组件 | 只保留 J2EE 架构识图和旧体系职责 |
| 24 | P2 | 综合答题模板 | 用于组织案例答案 |
