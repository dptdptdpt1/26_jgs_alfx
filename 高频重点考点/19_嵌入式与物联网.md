# 嵌入式与物联网

> 重要程度：P2  
> 考纲定位：嵌入式系统、实时系统和物联网场景架构。

## 优先掌握

1. 感知层、网络层、平台层、应用层的职责。
2. 嵌入式系统的实时性、资源受限、可靠性和功耗约束。
3. 网关、边缘计算、设备管理、OTA 和安全。
4. 数据上报、命令下发、弱网和离线处理。

## 概念和场景

| 重要度 | 内容 | 概念解释 | 场景式解释 |
| --- | --- | --- | --- |
| P0 | 感知层 | 采集物理世界数据 | 温湿度传感器采集仓库环境 |
| P0 | 网络层 | 负责设备连接和数据传输 | 设备通过 4G、Wi-Fi、LoRa 或以太网上报 |
| P0 | 平台层 | 设备接入、数据处理和管理 | 物联网平台管理设备状态和消息路由 |
| P0 | 应用层 | 面向业务使用数据和控制设备 | 运维人员查看设备告警并远程控制 |
| P1 | 实时性 | 在规定时间内响应 | 工业控制必须在毫秒级处理异常 |
| P1 | 边缘计算 | 在靠近设备处处理数据 | 网关本地过滤异常数据，减少云端压力 |
| P1 | OTA | 远程升级设备软件 | 批量修复设备固件漏洞 |
| P1 | 设备影子 | 云端保存设备期望状态和最新状态 | 设备离线时先记录命令，上线后同步 |

## 物联网架构答题顺序

1. 感知层采集：传感器、执行器、控制器。
2. 网络层传输：协议、网关、弱网重试。
3. 平台层处理：接入认证、消息队列、规则引擎、数据存储。
4. 应用层使用：监控、告警、控制、报表。
5. 安全和运维贯穿：身份、加密、权限、审计、OTA、设备生命周期。

## 常见问题与设计

| 问题 | 设计 |
| --- | --- |
| 设备弱网离线 | 本地缓存、断点续传、重试、设备影子。 |
| 海量设备接入 | 分层接入、消息队列、水平扩展、限流。 |
| 设备被伪造 | 设备证书、唯一身份、双向认证。 |
| 功耗敏感 | 降低采样频率、休眠唤醒、边缘过滤。 |
| 远程升级风险 | 分批 OTA、签名校验、失败回滚。 |

## 易混点

| 易混项 | 区分 |
| --- | --- |
| 边缘计算 vs 云计算 | 边缘计算靠近设备、低延迟；云计算集中处理、资源强。 |
| 网关 vs 传感器 | 网关负责协议转换和聚合；传感器负责采集。 |
| 实时性 vs 高性能 | 实时性强调截止时间；高性能强调吞吐或响应更快。 |

## 考纲外重要保留

数字孪生和具体 IoT 平台属于扩展内容；只在题干明确出现时，用“设备状态映射、仿真分析、远程运维”解释。
