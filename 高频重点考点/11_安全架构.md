# 安全架构

> 重要程度：P0  
> 考纲定位：信息安全技术、安全架构、安全策略、安全管理和软件脆弱性。

## 优先掌握

1. 认证、授权、审计、加密、签名、摘要的区别。
2. 接口安全：身份、权限、防篡改、防重放、限流、日志。
3. 数据安全：分类分级、传输加密、存储加密、脱敏、备份。
4. 网络边界：防火墙、DMZ、WAF、入侵检测、VPN。

## 概念和场景

| 重要度 | 内容 | 概念解释 | 场景式解释 |
| --- | --- | --- | --- |
| P0 | 认证 | 确认“你是谁” | 用户登录时校验账号、密码或证书 |
| P0 | 授权 | 判断“你能做什么” | 普通员工不能审批自己的报销单 |
| P0 | 审计 | 记录关键操作用于追踪 | 管理员修改权限后要留操作人、时间和内容 |
| P0 | 加密 | 防止数据被明文读取 | 身份证号入库前加密，传输走 HTTPS |
| P0 | 签名 | 验证来源和完整性 | 第三方回调携带签名，系统验证未被篡改 |
| P0 | 防重放 | 防止旧请求被重复提交 | 接口使用时间戳、随机数和签名 |
| P1 | RBAC | 基于角色授权 | 会计角色可查看发票，管理员可分配角色 |
| P1 | 最小权限 | 只授予完成任务所需权限 | 报表服务只读数据，不给写权限 |
| P1 | DMZ | 外网和内网之间的隔离区 | Web 服务器放 DMZ，数据库放内网 |

## 接口安全答题模板

1. 身份认证：Token、证书、OAuth2 或统一身份认证。
2. 权限控制：RBAC/ABAC、最小权限、接口级和数据级授权。
3. 传输保护：HTTPS/TLS。
4. 防篡改和防重放：签名、时间戳、随机数、请求唯一号。
5. 风险控制：限流、黑白名单、验证码、异常检测。
6. 审计追踪：记录请求方、时间、参数摘要、结果和异常。

## 数据安全答题模板

1. 分类分级：识别个人信息、敏感业务数据和普通数据。
2. 访问控制：按角色、岗位、数据范围授权。
3. 加密和脱敏：传输加密、存储加密、展示脱敏。
4. 生命周期管理：采集最小化、留存期限、备份恢复、安全销毁。
5. 审计和告警：异常访问、批量导出、越权操作可追踪。

## 易混点

| 易混项 | 区分 |
| --- | --- |
| 加密 vs 摘要 | 加密可解密还原；摘要不可逆，主要校验完整性。 |
| 签名 vs 加密 | 签名证明来源和完整性；加密保护内容不被读取。 |
| 认证 vs 授权 | 认证先确认身份；授权再判断权限。 |
| WAF vs 防火墙 | WAF 偏应用层攻击防护；防火墙偏网络访问控制。 |

## 考纲外重要保留

零信任、DevSecOps、云原生安全作为扩展概念保留；案例题中只按“身份可信、最小权限、持续验证、审计”回答，不展开产品体系。
